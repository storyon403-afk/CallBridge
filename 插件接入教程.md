# Plugin Integration Tutorial

Applies to CallBridge **0.0.2 / plugin API 1 (compatibility level 0.13.11)**, macOS Apple Silicon. Import existing packages in section 1, create voice/character/background packages from section 2, and adapt new models/algorithms in section 7.

Official samples download on demand through each feature's official-plugin page. See [catalog, generation, and publication](plugins/official/README.md). Unpublished packages explicitly show pending publication.

## 1. Import an existing plugin

1. Open the corresponding panel.
2. Choose local plugin import, select type, read requirements.
3. Choose a directory containing `manifest.json`, or `.cbplugin` / `.zip`.
4. Select the imported plugin to use it.

| Plugin | Import location | Use |
| --- | --- | --- |
| Chinese/English voices, engines, denoising | Audio simulation → audio plugins | Select voice; choose denoising separately in speech output |
| Personal voices | Personal-voice panel after language selection | Return to audio to select |
| Background audio | Mixing → file background | Set gain/play/loop |
| VRM character | Visuals → character replacement → virtual | Select, then preview |
| Image/video background | Visuals → background replacement | Select; retain person for background-only |

Install required engines first on their pages. Import never downloads dependencies, plays sound, or opens camera automatically.

## 2. Prepare resources

Create an empty `my-plugin` directory containing only import resources. Suggested names may change if the manifest matches.

| Plugin | `kind` | Resource | `dependencies` |
| --- | --- | --- | --- |
| Chinese voice | `voice-zh` | `voice.json`, complete current Pocket reference, ≤3,000,000 bytes | `[{"id":"pocket-tts-zh-4l-v1","version":"1.0.0"}]` |
| English voice | `voice-en` | `voice.safetensors`, English 2026.10, ≤16,000,000 bytes | `[{"id":"pocket-tts-en-v1","version":"2026.10.0"}]` |
| Background audio | `audio-background` | `background.wav`, PCM ≤32 MiB/30 seconds, 8–192 kHz mono/stereo | `[]` |
| Character | `avatar` | `character.vrm`, self-contained VRM 0.x/1.0 ≤64 MiB, humanoid/embedded PNG-JPEG | `[{"id":"avatar-holistic-v1","version":"1.0.0"}]` |
| Image | `background-image` | One `background.png` or `.jpg`, ≤16 MiB/4096×4096 | Same as avatar |
| Video | `background-video` | `background.mp4`, `.mov`, `.webm`, ≤64 MiB/120 seconds/1920×1080, one locally decodable video track | Same as avatar |
| Light denoising | `audio-denoise` | `settings.json`, example below | `[]` |

Video audio is excluded. WAV accepts integer 16/24/32 or finite in-range Float32. VRM forbids external textures/URLs/scripts; limits: 512 nodes, 128 meshes/materials, 64 images, 2,048 accessors, 4,096 bufferViews, ≤1,000,000 items/accessor, ≤4096×4096/texture, ≤32,000,000 pixels total, no cycles/multiple parents.

### Make a voice from personal recordings

1. Choose Chinese/English and prepare engine; Chinese also needs encoder.
2. Import owned/authorized **3–15-second PCM WAV**, complete generation.
3. Finder ⇧⌘G, locate by name:
   - Chinese: `~/Library/Application Support/CallBridge/Voices/pocket-v1/`; copy matching `<ID>.json` to `my-plugin/voice.json`.
   - English: `~/Library/Application Support/CallBridge/Voices/english-v1/`; identify using subdirectory `profile.json`, copy only sibling `voice.safetensors`.

Do not rename audio as JSON/safetensors or include English profile.json, originals, or previews in voice packages.

### Minimal example

Without existing assets, create `my-plugin/settings.json`:

```json
{"schema":1,"algorithm":"spectral-floor-v1","strength":0.5}
```

Strength `0–0.8`. This configures the existing Pocket-only denoiser; select plugin and clear output after import.

## 3. Generate manifest.json

Create `make_plugin.py` **outside** my-plugin. Requires Python 3; run from the script directory.

```python
# Purpose: derive actual resource lengths/hashes instead of entering them manually.
import hashlib
import json
from pathlib import Path

root = Path("my-plugin").resolve()
entry = "settings.json"                  # Resource filename from section 2
resource_names = [entry]                 # Ordinary resource packs allow one file
manifest = {
    "schema": 1,
    "api": 1,
    "id": "org.example.my-denoise",      # Your lowercase plugin ID
    "version": "1.0.0",
    "name": "My denoising",              # Display names may use Chinese
    "kind": "audio-denoise",            # Select from section 2
    "core_min": "0.13.10",
    "core_max": "0.14.0",
    "platforms": ["any"],
    "dependencies": [],                 # Fill according to section 2
    "permissions": [],
    "license": "CC0-1.0",               # Use the actual resource license
    "author": "Example",                # Author name
    "entry": entry,
    "files": [],
}

for name in resource_names:
    path = root / name
    if path.is_symlink() or not path.is_file():
        raise ValueError(f"Expected a regular resource file: {name}")
    data = path.read_bytes()
    manifest["files"].append({
        "path": name,
        "bytes": len(data),
        "sha256": hashlib.sha256(data).hexdigest(),
    })

(root / "manifest.json").write_text(
    json.dumps(manifest, ensure_ascii=False, indent=2) + "\n",
    encoding="utf-8",
)
print(root / "manifest.json")
```

```sh
python3 make_plugin.py
```

Expected:

```text
make_plugin.py
my-plugin/
├── manifest.json
└── settings.json
```

Rules:

- Lowercase letters/digits/hyphens/dots in ID, e.g. `org.example.my-avatar`; keep ID on updates.
- Versions use `1.0.0`. Range is `core_min ≤ plugin compatibility level < core_max`, limited to verified support. Release 0.0.2 retains compatibility 0.13.11; do not substitute public release numbering.
- Permissions must be `[]`; any means portable resources, not every OS supported.
- Relative paths permit ASCII letters/digits/dots/hyphens/underscores/separators, without traversal/absolute/symlinks.
- Exclude manifest itself from files. No scripts/.DS_Store/originals/undeclared files/custom fields.
- Regenerate after any resource change. Ordinary packages have one entry; engines/enhancement follow dedicated rules.

Package caps: 128 resources, 256 directory entries, 320,000,000 total bytes, 250,000,000/file; stricter type limits win.

## 4. Validate and package

Simplest: import the directory; App validates. Developers may use the built validator **from repository root**, replacing the last path:

```sh
rust/build/app/CallBridge.app/Contents/MacOS/callbridge-pocket \
  plugin-check "/absolute/path/my-plugin"
```

Success outputs ID/kind/entry JSON, exit 0. Checks only, no install/playback. Image/video requires sibling callbridge-media-check; do not copy worker alone. Build first if absent.

To share, run from parent:

```sh
python3 - <<'PY'
from pathlib import Path
from zipfile import ZipFile, ZIP_DEFLATED

root = Path("my-plugin").resolve()
with ZipFile("my-plugin.cbplugin", "w", ZIP_DEFLATED) as archive:
    for path in sorted(root.rglob("*")):
        if path.is_symlink():
            raise ValueError(f"Links are not allowed: {path}")
        if path.is_file():
            archive.write(path, path.relative_to(root).as_posix())
print("Created my-plugin.cbplugin")
PY
```

Manifest must be directly at archive root, not inside my-plugin/. Import/select the result. Acceptance of structure still requires purpose-specific preview/listening.

## 5. Fixed engines and speech enhancement

Offline installation supports **versions already recognized by this host**; renaming other models cannot integrate them.

| kind | Locked resources | Entry |
| --- | --- | --- |
| engine-zh | [package.json](rust/pocket/assets/package.json) complete files | conditioner.onnx |
| engine-zh-encoder | [encoder.json](rust/pocket/assets/encoder.json) | mimi_encode.onnx |
| engine-en | [english-package.json](rust/pocket/assets/english-package.json) files, not downloads | pocket-tts |
| engine-avatar | [plugin.lock.json](rust/avatar/plugin.lock.json) complete files | Listed resource, e.g. model/sample.vrm |

Prepare exact paths/names/lengths/SHA256; modify generator kind/entry/resource_names to all locked files, platform macos-arm64, empty dependencies/permissions. Exclude download archives/ready/generated config; lock manifests are not import manifests. Validate/import.

## 6. Updates and troubleshooting

Keep ID/increase version/regenerate/import. Highest version only; duplicate rejected; corrupt highest never falls back.

| Problem | Action |
| --- | --- |
| Missing manifest | Put at root |
| Length/hash mismatch | Restore complete bytes,regenerate/repackage |
| Type mismatch | Match kind/import selection |
| Dependency missing | Install exact specified engine/version |
| Extra files | Remove .DS_Store/scripts/samples/unpermitted files |
| Incompatible version | Use compatible host; adjust range only after verification |
| Engine validation fails | Restore pinned version; new self-declared hashes cannot bypass host |
| No adapter | Implement section 7; never disguise kind |
| No effect after import | Select/use;preview/playback/camera remain explicit |

Ordinary resources install at `~/Library/Application Support/CallBridge/Plugins/Local/<id>/<version>/`; engines at dedicated paths. No one-click uninstall:stop/quit before moving ordinary version directories. Never edit installed files directly.

## 7. Integrate a new speech model or video engine

**There is no general executable third-party plugin SDK.** New ONNX/Python/human-replacement/independent-animation packages need host adapters, not just manifests.

1. Define input text/PCM/images/tracking, output formats,rates/channels/dimensions/fps/platform/dependencies/size. See [validator](rust/pocket/src/plugins.rs).
2. Adapt using [Pocket](rust/native/pocket_provider.m),[English](rust/native/english_provider.m),[visual panel](rust/native/avatar_panel.m),[visual runtime](rust/avatar/src/app.mjs). Reuse PCM/composition/device paths; models do not own call devices.
3. Define load/ready/process/cancel/timeout/failure/release, bounded buffers, stale drops. Run inference/I/O off real-time; plugin failure must not destabilize output.
4. Extend [types/validation](rust/pocket/src/plugins.rs),versions/dependencies/files/contents. Executables require host-approved sources/hashes; manifests cannot grant arbitrary code permission.
5. Add [import help](rust/native/plugin_store.m),selection/availability/errors and Chinese-English-Japanese UI; update usage.
6. Test normal/corrupt/missing dependency/duplicate/cancel/timeout/crash then format/output. Capture/virtual/calls require corresponding authorization.
7. Document types/compatibility/acquisition/import, increment API for incompatible protocol, set minimum host for new capability, include minimal demo/actual evidence.

Run appropriate checks:

```sh
cargo fmt --manifest-path rust/Cargo.toml -- --check
cargo test --offline --manifest-path rust/Cargo.toml
sh rust/scripts/build-app.sh
python3 rust/scripts/check-local-plugins.py
python3 rust/scripts/check-localization.py
```

Pocket changes additionally reuse target:

```sh
cargo fmt --manifest-path rust/pocket/Cargo.toml -- --check
CARGO_TARGET_DIR="$PWD/rust/target" cargo test --offline --manifest-path rust/pocket/Cargo.toml
```

For avatar frontend changes, run `npm test` in `rust/avatar`. For C ABI changes, run `sh rust/scripts/check-abi.sh`. Build and unit-test results remain separate from device output and remote-call acceptance.
