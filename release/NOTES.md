# CallBridge 0.0.2

这次让文字输入更方便，也把常用设置收得更简洁了。

- 文字输入改成长条，右侧小箭头展开试听、音量和发送设置。
- 左侧六点把手可拖动窗口，拖边缘可以调整大小。
- 继续拖小并松手，会收成悬浮小组件；双击恢复刚才的尺寸和文字。
- 输入框和窗口外框更加圆润。
- 主面板可切换实色和半透明背景，会记住选择。
- 中文、英文、日文界面同步更新。
- 音频和混音设置更集中，插件可以按需下载或导入。

## 下载安装

需要 Apple Silicon Mac 和 macOS 26 或更新版本。下载 `CallBridge-0.0.2-macos-arm64.zip`，解压后把 App 拖进“应用程序”。升级前先按 ⌘Q 退出旧版。

App 尚未经过苹果发布签名和公证，第一次打开可能被系统拦截。打开方法、虚拟麦克风和 OBS 的配置请看随包的 `GETTING_STARTED.md`。

## Download

Use `CallBridge-0.0.2-macos-arm64.zip` on an Apple Silicon Mac running macOS 26 or later. Quit the previous version before replacing the App. This release adds a resizable text bar, a drag handle, rounded corners, floating widgets, and a solid/translucent background switch.

The App is not Apple signed or notarized. Follow `GETTING_STARTED.md` for opening the App and setting up audio or OBS Virtual Camera.
