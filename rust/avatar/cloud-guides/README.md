# CallBridge 云端 AI 能力接入

CallBridge 负责连接厂商能力、控制生命周期并最终交给现有媒体输出链路；不经营试衣商城、数字人内容平台或模型训练服务。

当前已实现 **4 家控制接口适配**，收录 **8 家代表性产品**。没有任何一家完成真实账号与通话端到端验证。不要将“接口适配”显示为“已接通”。原生设置、云端媒体接收、音画同步、Keychain 持久化和虚拟设备接线仍未实现。
