# Windows UI 对照验收

基准为当前 Windows 源码及沿用的 macOS 面板设计。下列 UI 修复包含在 0.0.4 测试包中，仍需逐项验收；维护者对 0.0.3 ui2 的历史确认不代表修复版已经通过。本清单用于逐项回归，不表示所有项目均有单独的通过记录。

## 不使用媒体设备的界面检查

1. 启动为 400×360 主面板，四个位置依次为音频模拟、混音设置、画面处理、声音转录；声音转录显示“Windows 暂不支持”并禁用。上方文字入口与背景材质切换；帮助、退出在窗口菜单与托盘。
2. 从主面板进入模块，主面板收为顶部标签。模块首页的“返回”可直接恢复父面板；标签也可双击恢复，允许两个面板同时展开。关闭主面板后仍可通过托盘重新打开。
3. 打开文字窗口，默认宽 560；紧凑态按两行正文自适应高度，展开为 560×420。输入三行中文并滚动、选择、撤销，展开/收起后不得出现半行截字；关闭后重开仍保留本次进程草稿，发送授权已撤销。重启不保留草稿。
4. 文字窗口直接显示发送设备；“设备…”直达输出设置。设备缺失时明确不可用、不替换选择；试听与发送选中同一设备时显示原因并禁用试听。音频概要的声音、输出可进入，音频插件与个人音色标记 Windows 暂不支持并禁用；导航的无障碍名称保留动作名称，不能只有状态值。
5. 混音设置保留文件背景；真实环境明确显示 Windows 暂不支持环境音采集，不提供可配置后就能开始的假入口。背景音量具有无障碍名称。
6. 主面板 → 画面处理 → 澄详情，两次跳转即可到“打开”；不创建“人物形象替换”“虚拟人物”中间标签。详情返回恢复画面首页；导入 VRM 和背景目录仍可用。目录与详情不启动 Node、WebView 或摄像头，重复进入同一页面不得创建第二个实例。
7. 人物详情选择搭配背景时保留人物；从根目录独立选背景时不默认添加人物。“不需要”仅清除配对的另一项。
8. 声音转录的保留页面明确写出 Windows 暂不支持实时变声与转录，不再要求用户配置无法接入的插件；不得采集、原声透传或显示假结果。
9. 云端服务可筛选服务和读取本地指南；Windows 未接入的配置保存、连接、提交操作禁用，不应创建远端请求。
10. 测试浅色、深色、高对比度、125%/150%/200% DPI、320 宽和窄窗口滚动、键盘焦点、中文输入法。缩小普通窗口至阈值后松开，应收为标签；文字紧凑态不得误收起，缩放后仍完整显示两行正文。
11. 产生超过五个收起标签，检查“…”展开、滚动、双击、拖离和返回顶部；两类置顶独立切换。多显示器布局尚未达到 Mac 的自动避让规则，应单独记录问题。

## 需要使用者明确启动媒体的检查

- 准备语音不连接输出设备。修改草稿、撤权、关闭、锁屏后，旧准备内容与倒计时失效。
- 5 秒倒计时只对已备好且允许发送的内容可用。留在 CallBridge 或计时器晚到超过 1 秒时返回待发；切换到其他程序才允许到点播放。
- 本机试听设备与发送设备不同。准备后试听仍可发送同一句；直接发送允许配置的文件混音，准备语音路径保持纯语音。
- 详情明确点击“打开”才创建运行画面；摄像头和视频输出仍需分别开启。回到目录不停止或改动运行快照；更改运行配置先停止旧管道，不能自动恢复采集/发送。
- 停止、关闭运行窗口、最小化、锁屏、睡眠后输出确实终止。OBS 摄像头和虚拟音频线在目标通话客户端的实际接收需另行验证。

实机记录请包含 Windows 构建号、显示缩放、包名、`Test-Windows.cmd` 日志及对应页面结果。交叉编译通过不代表上述界面或设备验收通过。
