# Windows UI 对照验收

基准为当前工作区 macOS `app.m`、`audio_panel.m`、`avatar_panel.m`、`service_panel.m`，而非旧版 Windows 截图。维护者已确认 0.0.3 ui2 的 Windows 测试通过；此清单用于逐项回归，不表示所有项目均有单独的通过记录。

## 不使用媒体设备的界面检查

1. 启动为 400×360 主面板，四个入口依次为音频模拟、混音设置、画面处理、声音转录。上方文字入口与背景材质切换；帮助、退出在窗口菜单与托盘。
2. 从主面板进入模块，主面板收为顶部标签。标签双击恢复，允许两个面板同时展开。关闭主面板后仍可通过托盘重新打开。
3. 打开文字窗口，默认 560×112；展开为 560×360。输入中文、选择文字、撤销，切换展开/收起后均保留；关闭后重开仍保留本次进程草稿，发送授权已撤销。重启不保留草稿。
4. 音频概要进入声音、输出、插件、个人音色，返回保留选择；各页底部状态、停止、文字入口固定可见。缺失设备保留原选择并标记不可用。
5. 混音设置有文件背景和真实环境两组；详情可返回。常驻背景与环境音采集明确待适配，不能出现已采集状态。
6. 画面处理 → 人物 → 虚拟人物 → 澄详情，以及背景 → 动态背景 → 流光详情，各层独立收为标签；目录与详情不启动 Node、WebView 或摄像头。重复进入同一页面不得创建第二个实例。
7. 人物详情选择搭配背景时保留人物；从根目录独立选背景时不默认添加人物。“不需要”仅清除配对的另一项。
8. 声音转录具备输入、变声音色、同时转文字、输出和文字结果路径；未接入引擎不可开始采集，不得原声透传或显示假结果。
9. 云端服务可筛选服务和读取本地指南；Windows 未接入的配置保存、连接、提交操作禁用，不应创建远端请求。
10. 测试浅色、深色、高对比度、125%/150%/200% DPI、320 宽和窄窗口滚动、键盘焦点、中文输入法。缩小普通窗口至阈值后松开，应收为标签；文字紧凑模式不会因 112 高度被误收起。
11. 产生超过五个收起标签，检查“…”展开、滚动、双击、拖离和返回顶部；两类置顶独立切换。多显示器布局尚未达到 Mac 的自动避让规则，应单独记录问题。

## 需要使用者明确启动媒体的检查

- 准备语音不连接输出设备。修改草稿、撤权、关闭、锁屏后，旧准备内容与倒计时失效。
- 5 秒倒计时只对已备好且允许发送的内容可用。留在 CallBridge 或计时器晚到超过 1 秒时返回待发；切换到其他程序才允许到点播放。
- 本机试听设备与发送设备不同。准备后试听仍可发送同一句；直接发送允许配置的文件混音，准备语音路径保持纯语音。
- 详情明确点击“打开”才创建运行画面；摄像头和视频输出仍需分别开启。回到目录不停止或改动运行快照；更改运行配置先停止旧管道，不能自动恢复采集/发送。
- 停止、关闭运行窗口、最小化、锁屏、睡眠后输出确实终止。OBS 摄像头和虚拟音频线在目标通话客户端的实际接收需另行验证。

实机记录请包含 Windows 构建号、显示缩放、包名、`Test-Windows.cmd` 日志及对应页面结果。交叉编译通过不代表上述界面或设备验收通过。
