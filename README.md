## 产品想法

有时你可以听，却不方便开口。输入想说的话，让 CallBridge 替你说出来。选个声音，加点背景音，或者换个虚拟形象加入通话。

## 展示

假设你正在进行微信语音或视频通话：左侧是操作，右侧是效果。
